# Política de seguridad

## Versiones soportadas

La rama `main` es la única versión mantenida públicamente.

## Reportar una vulnerabilidad

No publiques detalles de una vulnerabilidad en un issue abierto. Envía un reporte privado a los mantenedores del repositorio desde la opción **Report a vulnerability** de GitHub Security Advisories e incluye:

- la página o archivo afectado;
- pasos mínimos para reproducir el problema;
- impacto observado;
- una propuesta de corrección, si la tienes.

Responderemos tras validar el reporte y coordinaremos la divulgación de la solución.
